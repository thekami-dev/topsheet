## Why Topsheet

Every practical file starts with the same cover page, and retyping the same
institute, roll and teacher details each time gets old fast. Topsheet remembers
them for you, picks the right subjects for your department, and gives you a
clean PDF you can print or share straight away.

New here? [What is Topsheet?](https://blog.thekami.tech/posts/what-is-topsheet/) explains it in a few minutes.

## Features

**Create**
- Guided form for course, student and teacher details
- Remembers earlier entries, so repeat topsheets take seconds
- Clean, print-ready PDF output

**Your library**
- Everything you have made, organised by month
- Open, edit, share or delete any topsheet

**Always up to date, even offline**
- Institutes, departments and subjects load live from the cloud and update on their own
- Saved on your device after the first load, so the app keeps working without internet
- Your name, roll and teacher details stay on your device

**Make it yours**
- 16 colour palettes plus Dynamic colour that follows your wallpaper
- Tokyo Night by default, following your phone's light or dark mode
- Pure black option for AMOLED screens, with smooth theme transitions
- A short, friendly setup you can skip at any time

## Built with

| Area | Tools |
| --- | --- |
| App | [Flutter](https://flutter.dev) and Dart, Material 3 |
| PDF | [pdf](https://pub.dev/packages/pdf) and [printing](https://pub.dev/packages/printing) |
| Storage | [sqflite](https://pub.dev/packages/sqflite) and `shared_preferences` |
| Links | [url_launcher](https://pub.dev/packages/url_launcher) |
| CI/CD | GitHub Actions: signed release builds, GitHub Releases and Play Store publishing |

## Build from source

```bash

flutter run
```

Release builds:

```bash
flutter build apk --release
flutter build appbundle --release
```
